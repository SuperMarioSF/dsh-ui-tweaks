# dsh-ui-tweaks

针对 DSH `web` profile 的个人 UI 定制插件。

## 功能

- **Thinking 行**：流式输出时自动展开（约 5 行），并自动滚动跟随最新内容；完成后保持 5 行状态，滚动出屏幕后才自动收起；手动点击可完全展开；历史 think 可正常展开回看。
- **Tool call 行**：自动展开调用参数与结果，不自动收起；写文件类结果也保持展开显示。
- **紧凑顶栏**：对话 / 轨迹 Tab 与标题栏合并到同一行。
- **轨迹追踪**：轨迹工具栏提供“追踪”开关；开启后自动跟随最新记录，assistant 自动切到 Preview 并滚动到底部，thinking 自动展开；tool call 未返回时显示 Payload（第一层 JSON），返回后切换为 Result，并自动滚动。
- **侧边栏**：新建会话页不自动收起；进入已有对话页自动收起；手动展开后不会被反复收起。
- **更宽聊天区**：屏幕宽度 ≥1200px 时，聊天/输出宽度提升到 860px。
- **余额按钮 / 用量费用浮窗**：顶栏右侧显示余额；点击后弹出当前会话的按模型、按高峰/闲时统计的用量与预估费用浮窗（缓存输入、未缓存输入、输出、价格）。浮窗会聚合一次完整历史用于完整计价（不缓存完整历史、不把全部历史加载进聊天窗口），只保留聚合总量和有界请求明细；请求明细支持无限滚动分页加载更早记录，新请求会实时差分加入总量与明细。支持多套按生效时间切换的价格策略；历史加载中或拉取不完整时显示红色“正在加载历史记录”。包含“刷新余额”按钮；余额每 60 秒刷新，并在每个 turn 完成后刷新。压缩（compact）本身的模型调用也会计入用量与费用，请求明细中用“(压缩)”标注。子代理（subagent）的历史费用也会汇总进当前会话：总和统计按模型/时段合并子代理用量；请求明细中按创建时间混排，每个子代理显示为一行可展开的聚合（含嵌套子代理的总 token 与总价），展开后可查看该子代理自身按模型/时段的明细，嵌套子代理继续套娃展开。
- **底部统计栏**：显示 `tok 输入 RAW · 有效 EFFECTIVE · 输出 OUTPUT`，其中“输入”为总输入（缓存 + 未缓存），“有效”为未命中缓存输入。
- **Context Window 文字**：输入框的 context ring 旁常驻显示类似 `~256K / 1M` 的 used / total 文字。
- **输入框焦点**：点击输入框不会导致对话自动滚动暂停；偶发脱离自动滚动时会在无手动滚动的情况下自动恢复。

## 文件

- `lib/index.js` — Host 插件：暴露 `/dsh-ui-tweaks/balance`（使用已配置的 `DEEPSEEK_API_KEY` 调用 DeepSeek 余额接口）。
- `lib/client.js` — 浏览器插件：CSS、DOM 行为、余额/用量浮窗。
- `cordis.patch.yml` — profile 中注册插件行的示例。
